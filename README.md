# SportApp

**Project Goal**
Создать мобильное приложение «Спорт» для iOS и Android, которое помогает пользователям быстро находить спортивные секции, тренировки и мероприятия рядом с домом, получать полную информацию (цена, тренер, расписание) и записываться на пробные занятия.

## Инструкция по запуску

### Вариант 1: Запуск для разработки (С компьютера)

1. Скачайте файл проекта (папку SportApp или архив).
2. Разархивируйте папку в удобное место (например, на Рабочий стол).
3. Откройте терминал (PowerShell или командную строку) и перейдите в папку с проектом:

 + "`powershell" + 
cd C:\Users\ВашеИмя\Desktop\SportApp
 + "`" + 

4. Установите зависимости:

 + "`powershell" + 
npm install
 + "`" + 

5. Запустите сервер разработки:

 + "`powershell" + 
npx expo start -c
 + "`" + 

6. **Запустите на телефоне:** Откройте приложение **Expo Go** и отсканируйте QR-код.

### Вариант 2: Сборка в готовое приложение (APK для Android)

1. Установите EAS CLI:

 + "`powershell" + 
npm install -g eas-cli
 + "`" + 

2. Войдите в аккаунт Expo:

 + "`powershell" + 
npx expo login
 + "`" + 

3. Запустите сборку:

 + "`powershell" + 
eas build -p android --profile preview
 + "`" + 

4. Скачайте APK и установите на телефон.

Для iOS потребуется аккаунт Apple Developer.
