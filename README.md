# SportApp

**Project Goal:** Создать мобильное приложение «Спорт» для iOS и Android, которое помогает пользователям быстро находить спортивные секции, тренировки и мероприятия рядом с домом, получать полную информацию (цена, тренер, расписание) и записываться на пробные занятия.

## Инструкция по запуску

### Вариант 1: Запуск для разработки (Рекомендуемый)

1. Установите Node.js (версия 18+).
2. Перейдите в папку проекта:
   cd SportApp
3. Установите зависимости:
   npm install
4. Запустите сервер:
   npx expo start -c
5. Откройте Expo Go на телефоне и отсканируйте QR-код.

### Вариант 2: Сборка APK для Android

1. Установите EAS CLI: npm install -g eas-cli
2. Войдите: npx expo login
3. Запустите сборку: eas build -p android --profile preview
4. Скачайте APK и установите на телефон.

## Архитектура

- **Интерфейс:** React Native (Expo) + TypeScript
- **Навигация:** React Navigation
- **Данные:** Локальный каталог секций и AsyncStorage
